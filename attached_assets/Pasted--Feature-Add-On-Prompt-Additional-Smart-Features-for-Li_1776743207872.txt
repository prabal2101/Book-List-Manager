**Feature Add-On Prompt: Additional Smart Features for Library Book Tracker System**

Enhance the existing **Library Book Tracker System with AI Chatbot** by implementing the following additional features. Ensure all features are fully functional and integrated with the current system.

---

## 1. Trending Books System

### Requirements:

* Track number of times each book is borrowed
* Display:

  * “Trending Books” section on dashboard
  * Branch-wise trending books

### Implementation:

* Add field in Books table:

  * borrow_count (INTEGER, default 0)
* Increment borrow_count on each borrow

---

## 2. Book Reservation System

### Requirements:

* Allow users to reserve a book if no copies are available
* Maintain a queue for reservations
* Notify next user when book is returned

### Database:

Create table:

* reservations (reservation_id, user_id, book_id, status, timestamp)

### Logic:

* If available_copies == 0 → allow reservation
* On return:

  * Assign book to next user in queue

---

## 3. Smart Alerts / Notifications (UI-Based)

### Requirements:

* Show alerts for:

  * Upcoming due date
  * Overdue books

### Implementation:

* Display alerts in dashboard
* Highlight overdue books in red

---

## 4. Student Personal Dashboard

### Requirements:

* Show:

  * Currently borrowed books

  * Borrow history
  * Reserved books

### UI:

* Create separate student dashboard page
* Clean card-based layout

---

## 5. Book Rating & Review System

### Requirements:

* Users can:

  * Rate books (1–5 stars)
  * Write short reviews

### Database:

Create table:

* reviews (review_id, user_id, book_id, rating, comment)

### Display:

* Show average rating per book
* Show recent reviews

---

## 6. Difficulty Level Tag

### Requirements:

* Each book should have difficulty level:

### Database Update:

## 7. Fine Preview System

### Requirements:

* Show estimated fine before returning late book

### Logic:

* Define fine rate (e.g., ₹5 per day)
* Calculate:

  * overdue_days × fine_rate

### Display:

* Show message:

  * “Estimated Fine: ₹X”
